# 🌱 Smart Irrigation Weather Prediction System

An AI-powered Smart Irrigation System that helps farmers make intelligent irrigation decisions based on weather conditions and environmental factors. The system predicts whether irrigation is required by analyzing weather-related parameters, helping reduce water wastage and improve crop productivity.

## 🚀 Live Demo

🔗 https://smartirrigationweatherprediction.streamlit.app/

## 📌 Features

- 🌦️ Weather-based irrigation prediction
